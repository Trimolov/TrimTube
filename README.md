# ytterm

**ytterm** — консольный YouTube-плеер для Linux. Он позволяет искать видео на YouTube и запускать их без полноценного рабочего стола и оконного менеджера.

Проект использует Python для интерфейса, `yt-dlp` для поиска и получения данных о видео, а `mpv` для воспроизведения.

## Возможности

- Поиск видео на YouTube прямо из терминала.
- Поддержка запросов на русском и английском языках.
- Управление списком найденных видео с клавиатуры.
- Воспроизведение без отдельного графического окна, если система и сборка `mpv` поддерживают подходящий видеовывод.
- Возможность работы на минимальной Linux-системе без рабочего стола.

## Как работает видеовывод

`mpv` поддерживает несколько режимов вывода видео. Доступные режимы зависят от сборки `mpv` и системы.

- `tct` — отображает видео цветными символами прямо в совместимом терминале.
- `caca` — показывает видео в виде ASCII-графики.
- `drm` — выводит изображение напрямую на экран через Linux DRM/KMS. Этот режим предназначен для локальной консоли Linux без X11 или Wayland, но требует поддержки DRM и соответствующей сборки `mpv`.

Важно: `tct` и `caca` превращают кадры в текстовую графику, поэтому изображение будет выглядеть не как обычное полноразмерное видео. Режим `drm` выводит обычное изображение напрямую на экран, но использует физический экран, а не текстовую область терминала.

Обычный SSH-терминал не может показывать стандартное видео как полноценное изображение без поддержки специальных графических протоколов терминала. Для SSH обычно подходят текстовые режимы `tct` или `caca`, если они доступны.

## Требования

- Linux.
- Python 3.
- `yt-dlp`.
- `mpv` с подходящим видеовыводом.
- `ffmpeg` — рекомендуется для обработки и воспроизведения медиа.
- Совместимый терминал; для режима `drm` — локальная Linux TTY и поддержка DRM/KMS.

## Установка на NixOS

Для быстрого запуска можно открыть временное окружение с необходимыми программами:

```bash
nix-shell -p python3 yt-dlp mpv ffmpeg
```

Затем перейдите в каталог с проектом и запустите:

```bash
python3 ytterm.py
```

Если файл находится в домашней папке проекта, например `~/pro/ytterm.py`, используйте:

```bash
python3 ~/pro/ytterm.py
```

Команда `nix-shell -p ...` предоставляет пакеты только внутри текущего окружения. После выхода из него эти команды могут стать недоступны, если пакеты не установлены другим способом.

### Постоянная установка пакетов на NixOS

Если хотите, чтобы программы были доступны постоянно, добавьте их в конфигурацию NixOS или установите через свой привычный профиль Nix. Например, в `configuration.nix` можно добавить в список пакетов:

```nix
environment.systemPackages = with pkgs; [
  python3
  yt-dlp
  mpv
  ffmpeg
];
```

После изменения конфигурации примените её:

```bash
sudo nixos-rebuild switch
```

Если `environment.systemPackages` уже определён в файле, добавьте пакеты в существующий список, а не создавайте второе определение.

## Установка на Arch Linux

Установите зависимости:

```bash
sudo pacman -S python yt-dlp mpv ffmpeg
```

Перейдите в каталог проекта и запустите:

```bash
python ytterm.py
```

## Установка на Ubuntu или Debian

Установите базовые зависимости:

```bash
sudo apt update
sudo apt install python3 mpv ffmpeg
```

`yt-dlp` может отсутствовать в репозитории или быть слишком старым. Установите актуальную версию `yt-dlp` способом, рекомендованным для вашего дистрибутива, затем запустите:

```bash
python3 ytterm.py
```

## Запуск

1. Установите зависимости.
2. Скачайте или клонируйте репозиторий.
3. Откройте терминал в каталоге проекта.
4. Запустите `python3 ytterm.py` (на некоторых системах команда может быть `python ytterm.py`).
5. Введите поисковый запрос и выберите видео с клавиатуры.

Например, чтобы клонировать репозиторий, если он размещён на GitHub:

```bash
git clone https://github.com/USERNAME/REPOSITORY.git
cd REPOSITORY
python3 ytterm.py
```

Замените `USERNAME/REPOSITORY` на адрес своего репозитория.

## Проверка видеовыводов mpv

Чтобы посмотреть режимы, доступные в вашей сборке:

```bash
mpv --vo=help
```

Если `tct`, `caca` и `drm` отсутствуют, текущая сборка `mpv` может не поддерживать нужный режим. Установите сборку с подходящими видеодрайверами или используйте доступный режим.

Для проверки `yt-dlp` и `mpv`:

```bash
yt-dlp --version
mpv --version
```

## Частые проблемы

### Видео не отображается, но звук есть

Возможно, `mpv` выбрал аудиопоток или неподходящий режим видеовывода. Убедитесь, что используется версия программы из актуального файла проекта, а `mpv` поддерживает выбранный видеорежим.

### Ошибка HTTP 403 от YouTube

YouTube иногда меняет способы выдачи медиа и может отклонять старые запросы. Обновите `yt-dlp` и попробуйте снова. При необходимости обновите `mpv` и `ffmpeg`.

### Не найден `yt-dlp` или `mpv`

Проверьте, что зависимости установлены и доступны в текущем окружении:

```bash
command -v yt-dlp
command -v mpv
```

На NixOS убедитесь, что запустили программу внутри окружения, где доступны необходимые пакеты.

### Режим `drm` не запускается

Запускайте его из локальной Linux TTY, а не из обычного окна терминала или SSH-сеанса. Проверьте доступность DRM/KMS, права доступа к устройствам и поддержку `drm` в сборке `mpv`. Не все видеокарты, драйверы и сборки поддерживают этот режим одинаково.

### Русский текст отображается некорректно

Убедитесь, что терминал использует UTF-8. При необходимости установите подходящие шрифты и локаль для своего дистрибутива.

## Безопасность и ограничения

- Для поиска и воспроизведения используется сторонний инструмент `yt-dlp`.
- Доступность видео зависит от YouTube, региона, авторизации и ограничений конкретного ролика.
- Проект не обходит платный доступ, приватность видео или другие ограничения доступа.
- Интерфейс и поддерживаемые видеорежимы зависят от версии файла проекта, `mpv` и системы.
